# Product Roadmap

## Phase 0 — Foundation (current)

Monorepo, responsive design system, versioned API, auth seam, repository/provider/LLM contracts, database migration, Celery foundation, quality commands, Docker services, and architecture documentation.

## Phase 1 — Stock Data

Canonical stock master, symbol resolver, one production provider adapter + normalizer, provenance, freshness rules, fallback contract tests, and PostgreSQL repositories.

## Phase 2 — Watchlist

Email/password sessions, ownership enforcement, watchlist groups, preferences, mobile research feed, quotas through entitlements, and real API client generation.

## Phase 3 — Stock Research

Deterministic financial metrics, historical comparisons/percentiles, industry benchmarks, 12-dimension context model, evidence records, and versioned snapshots without LLM generation.

## Phase 4 — AI Research

LLM gateway adapters, structured stock health research, research Q&A with evidence, SSE task progress, shared snapshot deduplication, usage audit, and safety evaluation.

## Phase 5 — Financial Report

Statement normalization, report version comparison, deterministic ratios, structured interpretation, evidence-level citations, and historical report archive.

## Phase 6 — Event Engine

Announcement/news ingestion, canonical event taxonomy, clustering, change detection, materiality rules, and source conflict handling.

## Phase 7 — Notification

User alert rules, digest jobs, in-product/email channels, quiet hours, delivery idempotency, retries, and preference enforcement.

## Phase 8 — Factor / Backtest

Versioned factor definitions, deterministic engines, survivorship-bias controls, research simulations, reproducible datasets, and explicit non-advice language.

## Phase 9 — Commercialization

Plan catalog, entitlement service, usage limits, subscriptions, payment integration, operational admin, audit, observability, privacy, and production deployment hardening.
