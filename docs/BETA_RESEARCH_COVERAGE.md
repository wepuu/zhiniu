# Phase 13 Beta Research Coverage

Phase 13 is an internal operations and product-learning loop for the controlled Beta. It does not
expand the product into investment advice, full-market data operations, or behavior tracking.

## Priority universe

`beta_research_universe_snapshots` is immutable. A snapshot combines operator-pinned acceptance
symbols with symbols currently retained by active Beta watchlists. Members store only the global
symbol and reason flags; user identifiers are not copied into the universe.

```text
uv run python -m zhaoniu_api.cli build-beta-research-universe
```

## Coverage contract

Each stock is evaluated on three independent axes:

- availability: whether a retained artifact exists and is usable;
- freshness: whether that artifact is current for the deterministic dimension threshold;
- source health: the latest relevant provider run or retained snapshot health.

The dimensions are market, financial, fundamental research, industry, peer research, event radar,
screening, and AI research. `unsupported`, `disabled`, and `blocked_by_policy` are explicit states,
not errors and not zero scores. A no-event radar remains a valid retained artifact.

```text
uv run python -m zhaoniu_api.cli build-research-coverage-snapshot
uv run python -m zhaoniu_api.cli show-stock-coverage 600519
```

The public read API is `GET /api/v1/stocks/{symbol}/coverage`. The stock research page shows a
compact five-dimension explanation without ranking or recommendation language.

## Dataset policy

`DatasetPolicyRegistry` is executable. AKShare-backed source collection is allowed only when
`COVERAGE_USAGE_SCOPE=development_evaluation`. Internal Beta, external Beta, and production scopes
fail closed until a licensed data policy is configured. AI is not automatically generated by this
phase under any scope.

## Deterministic bounded backfill

Planning reads an immutable coverage snapshot and emits only allow-listed actions in dependency
order. Running is always an explicit operator action. One call processes at most
`COVERAGE_BACKFILL_BATCH_SIZE` items sequentially; there is no Celery Beat schedule.

```text
uv run python -m zhaoniu_api.cli plan-coverage-backfill
uv run python -m zhaoniu_api.cli run-coverage-backfill RUN_ID
uv run python -m zhaoniu_api.cli coverage-backfill-status RUN_ID
```

Every item retains the reason, before/after fingerprint, provider-call count, row counts, duration,
status, and redacted exception class. Expired 30-minute leases are recovered automatically. If an
operator has confirmed that a worker process terminated, they can return only its running items to
pending with `recover-coverage-backfill RUN_ID` before rerunning the bounded batch.

Provider failure is recorded per item and does not fabricate a successful result. A downstream
artifact is projected into the research feed only when the artifact fingerprint changed.

## Feedback and learning

Authenticated, CSRF-protected users may submit a bounded structured message through
`POST /api/v1/me/beta-feedback`. The form explicitly warns against secrets and sensitive personal
information. Operators can list feedback and move it from `new` to `triaged` or `resolved` through
the CLI.

```text
uv run python -m zhaoniu_api.cli list-beta-feedback
uv run python -m zhaoniu_api.cli update-beta-feedback-status FEEDBACK_ID triaged
uv run python -m zhaoniu_api.cli generate-beta-learning-report --days 7
uv run python -m zhaoniu_api.cli generate-beta-learning-report --days 30
```

Learning reports contain aggregate adoption proxies already present in product records, coverage
gaps, backfill outcomes, and feedback categories. User-level groups smaller than
`BETA_LEARNING_MIN_GROUP_SIZE` are emitted as `<N`. Metrics requiring page-view telemetry are listed
as unavailable rather than inferred.
